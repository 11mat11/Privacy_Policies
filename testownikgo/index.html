Policy Summary: TestownikGO is an offline educational application. The Application itself does not collect, transmit, or share personal data with the Developer or third parties. Data used to provide the application's functionality is processed locally on the user's device.

1. Scope and Application Identification

This Privacy Policy describes the data handling practices of the mobile application TestownikGO (Package ID: com.s11mat11.TestownikGO, the “Application”), published and maintained by 11mat11 (the “Developer”).

The policy applies to the version of TestownikGO distributed through Google Play and describes how the Application accesses, processes, stores, and handles user data.

2. Data Collection, Transmission, and Sharing

TestownikGO is designed to function locally and does not provide a server-based account or cloud-sync feature.

  • No collection by the Developer: The Developer does not receive or maintain personal data from the Application.
  • No transmission by the Application: TestownikGO does not intentionally initiate network connections or upload user data to external servers, cloud databases, or remote endpoints.
  • No third-party tracking or advertising: The Application does not use analytics, advertising, behavioral profiling, remote telemetry, or remote crash-reporting SDKs.
  • No sale or sharing: The Application does not sell or share user data with third parties for their own purposes.

3. Local Data and File Handling

Data required for the Application's functionality is handled locally on the user's device.

  • User-selected files: Question sets such as .txt and .zip files are opened only after the user selects them through the Android system file picker. Their contents are processed locally by the Application.
  • Quiz progress and preferences: Test progress, repetition counts, settings, and other application state may be stored in the Application's local storage.
  • No remote synchronization: Locally stored application data is not synchronized with a Developer-controlled server or database.
  • Original user files: Files that the user selects from another location on the device remain under the control of Android and the user. Uninstalling TestownikGO does not claim to delete the user's original files outside the Application's private storage.
Android system backup: The Application itself does not upload its data to a server. The current Android manifest allows the application to participate in Android's system backup and restore infrastructure. Depending on the device and the user's system backup settings, Android or Google system services may back up or restore application data. Such system-managed operations are not initiated by TestownikGO and are governed by the applicable Android/Google settings and policies.

4. Data Retention and Deletion

  • Local control: Users can remove locally stored application data by clearing TestownikGO's storage through Android system settings.
  • Uninstallation: Uninstalling the Application removes its application-private data according to Android's storage and backup mechanisms.
  • No Developer-side deletion request: Because the Developer does not maintain a server-side account or user database for TestownikGO, there is no separate Developer-controlled database from which users need to request deletion.

5. Privacy, GDPR, and International Requirements

TestownikGO is designed around data minimization and local processing. The Application does not transmit personal data to the Developer or to third-party services for analytics, advertising, profiling, or remote monitoring.

6. Children's Privacy

TestownikGO does not collect or transmit personal information from users, including children. The Application does not provide user accounts, advertising profiles, analytics profiles, or a remote user database.

7. Changes to This Privacy Policy

This Privacy Policy may be updated when the Application's functionality or data practices change, or when applicable requirements change. The latest version will be published at this URL together with an updated revision date.
