Summary: TestownikGO is a 100% offline educational tool. It does not collect, track, or share any personal information. Internet access is completely disabled.

1. Developer and Application Identification

This Privacy Policy governs the mobile application TestownikGO (Application ID: com.s11mat11.TestownikGO), published and maintained by 11mat11 ("Developer").

2. Zero Data Collection and Transmission

  • No Personal Data: The Application does not collect, process, record, share, or sell any personal data, usage analytics, or device identifiers.
  • No Internet Connection: Internet access is explicitly blocked within the Application (android.permission.INTERNET is removed). The Application cannot establish network connections or transmit data to any external server.
  • No Third-Party SDKs: The Application contains no third-party tracking, advertising, or cloud services (such as Firebase, Google Analytics, or AdMob).

3. Local Storage and File Access

  • Question Files (.txt, .zip): Test files are selected strictly by the user via the system document picker. These files are processed entirely in the local memory of the device and never leave the device.
  • Quiz Progress & Settings: User preferences and current quiz progress are stored locally on the device using local storage (AsyncStorage).

4. Data Retention and Deletion

Because all data is stored exclusively on your device, you retain full control. You can permanently delete all stored data and settings at any time by clearing the Application's storage/cache in Android Settings or by uninstalling the Application.

5. Children’s Privacy

The Application does not collect any data from any user, including children under the age of 13 (or under 16 in the EEA), complying fully with COPPA and GDPR regulations.
